🙋 Frequently Asked Questions

Is it safe to use?

Absolutely. The number one rule of this project is backup first. The program creates a restore point automatically. You cannot permanently damage your save unless you turn off backups, which we strongly advise against. We also scan for dangerous edits and warn you.

Do I need to know how to code?

Not at all. The interface lists your game's save data as simple words. You'll see "Charisma Level" not "Charisma_Stat_bin_0ff". Type the new value and click save.

Does it work offline?

Yes, completely. It's a local program. It does not connect to the internet. Your save data never leaves your computer.

What operating systems are supported?

Currently Windows 10 and Windows 11 (64-bit). This is a community project, so other OS versions may come later based on demand.

Is it really free?

Yes, it's open source (MIT license). You can even look at the code on GitHub. No paid tiers, no premium locks.

What if the game I want isn't listed?

You can request support on our GitHub issues page. We also provide a "Custom Editor" mode where you can manually point out which block in the save represents a value.
